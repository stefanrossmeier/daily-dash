# Code of Conduct

DailyDash aims to be a technically rigorous and welcoming open-source project. Participation in
issues, pull requests, reviews, and other project spaces should make it easier for people to reason
about the software and improve it.

## Expected behavior

Participants should:

- discuss ideas and code on their technical merits;
- be specific and constructive when disagreeing;
- assume good faith while still asking for evidence and reproducibility;
- respect different levels of experience and communication styles;
- keep reviews focused on the contribution rather than the contributor;
- disclose relevant conflicts of interest;
- respect privacy and never repost another person's sensitive information.

## Unacceptable behavior

The project does not accept harassment, threats, discriminatory or demeaning language, sexualized
attention, deliberate intimidation, doxxing, sustained personal attacks, spam, or knowingly
publishing credentials/private data.

## Scope and enforcement

This policy applies to project-controlled spaces and to conduct performed while representing the
project. The repository owner may edit/remove contributions, lock discussions, issue warnings, or
restrict participation when behavior materially harms contributors or the project.

For sensitive conduct reports, contact the repository owner through a private GitHub channel when
available rather than opening a public issue. Reports will be considered in context and handled as
privately as practical.

Good-faith technical disagreement, including strong criticism of code or architecture, is welcome;
personal hostility is not.
